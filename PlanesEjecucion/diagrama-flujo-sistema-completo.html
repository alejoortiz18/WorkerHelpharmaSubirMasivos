2. Envío de archivos procesados — APIs → AWS S3

Worker 2 y MVC no suben directamente a S3. Envían el PDF por HTTPS a las APIs Helpharma; el backend de la API 2 recibe el anexo y lo persiste en S3.

flowchart LR W2["Worker 2\n10.0.0.3"] -->|"HTTPS POST"| API1["API 1\nDatosSoportes\napi-soportes.helpharma.com.co"] MVC["Portal MVC\nIIS"] -->|"HTTPS POST\n(reproceso)"| API1 API1 -->|"JSON datos soporte"| API2["API 2\nSoporte físico\nintranet.helpharma.com"] W2 -->|"multipart:\ncódigo + metadatos\n+ anexo PDF"| API2 MVC -->|"multipart:\ncódigo + metadatos\n+ anexo PDF"| API2 API2 -->|"Backend Helpharma\nalmacena anexo"| S3[("AWS S3\nPDF definitivo")] style W2 fill:#276749,color:#fff style MVC fill:#c05621,color:#fff style API1 fill:#744210,color:#fff style API2 fill:#744210,color:#fff style S3 fill:#c53030,color:#fff
API 1: POST /api/DocSoporte/soportes/DatosSoportes — consulta datos del soporte por código de barras.
API 2: POST /api/v1/soporte/fisico — recibe el PDF completo en el campo anexo (multipart/form-data). Tras respuesta exitosa, el archivo procesado queda en AWS S3 del lado Helpharma.

Correo (Worker 2): se envía un correo por lote cuando OpenAI falla por error de servicio (cuota, timeout, etc.). Incluye usuario, fecha, cantidad de archivos, mensaje de error y ruta UNC de noprocesados. SMTP Office 365 — destinatarios en configuración del servicio.
